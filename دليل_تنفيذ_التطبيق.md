### A2. أضف دالتين في `lib/data/datasources/remote/content_remote_datasource.dart`
```dart
import '../../models/comment_model.dart';

// داخل ContentRemoteDataSource:

Future<List<CommentModel>> getComments(int postId, {int page = 1}) async {
  // نبني الـquery بـ & لأن apiBase يستخدم ?rest_route=
  final url = '${ApiConstants.comments}&post=$postId&page=$page&per_page=20';
  final res = await _dio.get(url);
  final body = res.data;
  final list = (body is Map && body['data'] is List)
      ? (body['data'] as List)
      : const [];
  return list
      .map((e) => CommentModel.fromAlmadarJson(e as Map<String, dynamic>))
      .toList();
}

/// يعيد (التعليق، هل نُشر مباشرة، رسالة).
Future<(CommentModel, bool, String)> addComment({
  required int postId,
  required String content,
  int parent = 0,
  String? authorName,
  String? authorEmail,
}) async {
  final data = <String, dynamic>{'post': postId, 'content': content, 'parent': parent};
  if (authorName != null && authorName.isNotEmpty) data['author_name'] = authorName;
  if (authorEmail != null && authorEmail.isNotEmpty) data['author_email'] = authorEmail;
  final res = await _dio.post(ApiConstants.comments, data: data);
  final d = ((res.data as Map)['data'] as Map).cast<String, dynamic>();
  return (
    CommentModel.fromAlmadarJson((d['comment'] as Map).cast<String, dynamic>()),
    d['approved'] as bool? ?? false,
    d['message'] as String? ?? '',
  );
}
```
> ملاحظة: التوكن يُضاف تلقائيًا في `DioClient` من الـ interceptor إن كان المستخدم مسجّلًا؛ إن لم يكن، أرسل `authorName`.

### B3. دوال في `auth_remote_datasource.dart` (+ الواجهة abstract)
```dart
Future<UserModel> verifyEmail(String email, String code) async {
  final res = await _dio.post(ApiConstants.authVerifyEmail,
      data: {'email': email, 'code': code});
  final d = _data(res.data);
  final token = await _secureStorage.read(key: ApiConstants.tokenKey) ?? '';
  return UserModel.fromJson((d['user'] as Map?)?.cast<String, dynamic>() ?? {}, token: token);
}

Future<void> resendCode(String email) async {
  await _dio.post(ApiConstants.authResendCode, data: {'email': email});
}
```

## المهمة C — مركز الإشعارات لا يبقى فاضيًا بدون Firebase

حاليًا `receivedNotificationsProvider` يقرأ من التخزين المحلي فقط (يمتلئ من FCM). بدون Firebase يبقى فاضيًا. اجعله يدمج **آخر الأخبار العاجلة من الـAPI**:

في `content_providers.dart` (عدّل المزوّد):
```dart
final receivedNotificationsProvider =
    FutureProvider<List<Map<String, dynamic>>>((ref) async {
  final local = await NotificationStore.getAll();
  final out = [...local];
  try {
    final breaking = await ref.read(newsRemoteDataSourceProvider).getBreakingNews();
    for (final a in breaking) {
      if (out.any((n) => n['post_id']?.toString() == a.id.toString())) continue;
      out.add({
        'title': 'عاجل: ${a.title}',
        'body': a.excerpt,
        'post_id': a.id.toString(),
        'image': a.featuredImageUrl,
        'time': a.datePublished,
      });
    }
  } catch (_) {}
  out.sort((a, b) => (b['time'] ?? '').toString().compareTo((a['time'] ?? '').toString()));
  return out;
});
```
> بكده المستخدم اللي يفعّل التنبيهات يلاقي آخر العاجل في المركز حتى قبل تفعيل Firebase.
